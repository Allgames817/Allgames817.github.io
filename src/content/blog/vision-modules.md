一套视觉系统不只是一个识别模型。下面按信息流整理一种概念上的划分方式，用于展示技术笔记的结构，不对应某支队伍的实际系统。

## 让信息流成为线索

可以先把系统分成图像输入、视觉处理和系统接口三个部分。每一部分应说明输入、输出和失败时的行为。

- 图像输入：图像从哪里来，是否带有时间信息？
- 视觉处理：输出什么结果，怎样表达不确定或无结果的情况？
- 系统接口：下游如何知道数据是否有效？

## 接口比名字更重要

即使两个模块使用相同的名称，也可能有不同的数据约定。坐标、时间与有效性标志应明确记录，避免在联调时依赖口头理解。

```python
# 示意数据结构，字段由真实系统需求决定
result = {
    "timestamp": None,
    "detections": [],
    "valid": False,
}
```

## 为失败情况留出位置

无检测结果、图像缺失与接口中断应当被分别识别。说明“没有输出意味着什么”，也是系统设计的一部分。
